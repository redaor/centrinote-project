# 📸 Dossier Images Centrinote

Ce dossier contient toutes les images et icônes de la marque Centrinote.

## 📁 Structure créée

```
public/images/centrinote/
├── icons/          # Icônes PWA et favicons
│   ├── pwa-192x192.png (à créer)
│   ├── pwa-512x512.png (à créer)
│   └── favicon.ico (à créer)
├── logo/           # Logos de la marque
└── screenshots/    # Captures d'écran (optionnel)
```

## 🎨 Spécifications des icônes PWA

### Icônes requises:
- **pwa-192x192.png** : 192x192px (icône PWA standard)
- **pwa-512x512.png** : 512x512px (icône PWA haute résolution)
- **favicon.ico** : 16x16, 32x32, 48x48 (multi-size ICO)
- **favicon.svg** : SVG scalable (optionnel, moderne)

### Design recommandé:
- **Fond**: Gradient bleu (#2563eb) → teal
- **Icône**: BookOpen (symbole de Centrinote)
- **Style**: Coins arrondis (rounded-xl)
- **Couleurs**: 
  - Bleu principal: `#2563eb`
  - Teal secondaire: `#14b8a6`

## 📝 Notes

- Les icônes PWA doivent être accessibles depuis `/images/centrinote/icons/`
- Le manifest PWA référence ces icônes
- Format PNG recommandé pour compatibilité maximale
